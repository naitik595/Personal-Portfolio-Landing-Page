A responsive personal portfolio website built to showcase my frontend learning journey, skills, projects, and goals as an aspiring full-stack developer.

## About the Project

This portfolio was designed and built from scratch using HTML5 and CSS3. It documents my current progress as I learn web development and build projects step by step.

## Features

- Responsive navigation
- Mobile-friendly layout
- Tablet-responsive layout for 768px–1024px screens
- Responsive hero section
- About section with learning facts
- Skills showcase
- Project cards
- Learning journey timeline
- Contact section
- Responsive footer
- Dark developer-focused interface
